# Design Patterns

This directory contains implementations of common software design patterns, showcasing principles like Open/Closed Principle, loose coupling, and dynamic behavior composition.

- **0-factory.py**: Factory Pattern (Extending a registry without modifying core creation logic).
- **1-observer.py**: Observer Pattern (Decoupling publishers and subscribers with topic filtering).
- **2-decorator.py**: Decorator Pattern (Dynamically wrapping and extending object behavior).
